# Formation API

API de gestion de formations (Django REST Framework).

## Démarrage

1. Créer l'environnement virtuel : `py -m venv .venv`
2. L'activer : `.\.venv\Scripts\Activate.ps1`
3. Installer : `pip install -r requirements/dev.txt`
4. Copier `.env.example` vers `.env` et renseigner les valeurs
5. Lancer : `python manage.py runserver`
